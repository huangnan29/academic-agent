# AIWritePaper 公开页面质量基线

## 调研边界

- 调研日期：2026-08-12。
- 只观察 `https://www.aiwritepaper.com/` 无需登录即可看到的主页结构、产品类型与范文分类。
- 未登录、未付费、未绕过验证码或访问控制，未复制范文正文，未将第三方内容打包进应用。
- 页面中的生成时长、引用真实性、检测结果与质量描述均按“站点自述”处理，不视为独立核验结论。

## 公开类型观察

主页可见的产物入口包括毕业论文、自定义论文、期刊论文、文献综述、期末论文、开题报告、任务书，以及 PPT/演讲稿等。公开范文分类覆盖工学、机械设计、电路设计、物理、化学、管理、地理、教育、艺术、经济、法学、医学、理学、文学、开题报告与 PPT 等方向。

来源：<https://www.aiwritepaper.com/>

## 转化为本产品的独立质量门槛

1. 先建立研究简报，再生成三级大纲，避免一次性生成整篇长文。
2. 提纲包含章节目标、目标篇幅与允许引用的文献 ID。
3. 正文按章节生成，生成后可继续对话、编辑、扩写或精简。
4. 文献检索记录与正文引用映射分开保存；无法映射的引用必须显式提示。
5. “检索到元数据”“存在摘要”“读取到全文”“能支持当前主张”是四个不同状态。
6. 不允许模型编造 DOI、页码、样本、实验、问卷、统计结果或工具执行状态。
7. 导出前运行篇幅、占位符、重复段落与引用映射检查，但不把启发式检查冒充人工学术审核。
8. 演示数据持续标注为演示，不允许纳入真实项目引用。

## 首版已实现映射

| 公开能力方向 | 本项目实现 |
| --- | --- |
| 多学科、多论文类型 | 新建项目时配置论文类型、学科、语言、篇幅与要求 |
| 三级大纲 | 模型先输出结构化大纲，解析后生成分级章节 |
| 长文与连续修改 | 分章生成、本机保存、全稿/章节上下文对话 |
| 参考文献 | OpenAlex、Crossref 与可选 MCP 文献工具 |
| 表、公式、代码等学科产物 | 通过研究要求与章节目标交给所选模型；无真实数据时禁止冒充实测结果 |
| 质量控制 | 引用 ID 白名单、映射记录、篇幅/重复/占位符检查、过程面板 |

## 未核验项

- 站点登录后或付费范文的完整正文质量。
- 站点宣称的生成时间、引用真实性、查重或 AIGC 检测结果。
- 本项目与该站点在相同题目、相同模型和相同文献条件下的盲评对比。
